# گزارش فاز ۸ — Installer ویندوز

## هدف

آماده‌سازی ساختار نصب‌کننده MSI برای Windows x64 با WiX Toolset 6.0.2، بسته‌بندی runtime مربوط به Qt و تعریف رفتار نصب/ارتقا/حذف با حفظ داده‌های کاربر.

## تغییرات

- installer/InvoiceMaker.wxs: تعریف MSI، نصب در Program Files، میانبر منوی Start، CAB جاسازی‌شده، UpgradeCode ثابت و جلوگیری از Downgrade.
- installer/InvoiceMaker.wixproj: پروژه SDK-style برای WiX 6.0.2 و HarvestDirectory برای فایل‌های خروجی.
- scripts/build-installer.ps1: پیش‌بررسی نسخه Go/Qt/WiX، Build برنامه، اجرای windeployqt، بررسی DLLهای کلیدی و ساخت MSI.
- scripts/test-installer.ps1: بررسی اولیه جدول فایل MSI برای executable و runtimeهای ضروری.
- docs/WINDOWS_INSTALLER.md: فرمان‌های ساخت و چک‌لیست آزمون روی ماشین مجازی تمیز.

## وضعیت اعتبارسنجی

این نشست امکان اجرای Windows PowerShell، Go/Qt/MinGW و WiX محلی را ندارد. بنابراین تست Build، ساخت MSI، نصب واقعی و آزمون حفظ داده انجام‌شده محسوب نمی‌شوند. تست CI فاز ۷ نیز در آخرین اجرای قابل مشاهده failure بوده و لاگ جزئی در دسترس نیست؛ این موضوع باید جداگانه بررسی شود.

## ریسک‌ها و محدودیت‌ها

- برنامه فعلی به محیط Qt/MinGW سازگار نیاز دارد و اسکریپت فقط وجود برخی فایل‌های runtime را بررسی می‌کند؛ وابستگی‌های پنهان ممکن است باقی بمانند.
- روش برداشت فایل‌ها با WiX Heat باید در WiX 6.0.2 نصب‌شده واقعاً آزمایش شود.
- امضای MSI، آیکون، UI تعاملی نصب و تست واقعی rollback/upgrade در این فاز تکمیل نشده‌اند.
- حذف‌کننده عمداً دیتابیس کاربر را حذف نمی‌کند؛ سیاست نگهداری و Backup باید جداگانه مستند و آزمایش شود.
