# تصمیم‌های فناوری و ریسک‌ها

## وضعیت شواهد
مخزن GitHub در بررسی آغازین فقط یک Commit با پیام Initial commit داشت و اندازه گزارش‌شده آن صفر بود؛ Branch قابل مشاهده main بود. بنابراین هنوز سورس، فایل تنظیمات Build یا مستندات محیطی برای تأیید سازگاری وجود نداشت. این وضعیت بر اساس دسترسی GitHub در زمان فاز صفر است و بررسی محیط محلی Windows انجام نشده است.

## مواردی که هنوز تأیید نشده‌اند
- نسخه واقعی Go، Qt، MinGW، CMake، Ninja و WiX
- سازگاری ABI و پشتیبانی فعال Bindingهای Go/Qt از Qt 6.12
- مجوز Qt و اثر آن بر توزیع تجاری
- نیازمندی‌های CGO، کامپایلر و DLLهای SQLite
- پشتیبانی واقعی RTL و فونت در گزینه‌های PDF
- مجوزها و محدودیت‌های کتابخانه XLSX
- اجرای WiX روی محیط هدف و بسته‌بندی وابستگی‌ها

## ریسک‌های مهم
1. **اتصال Go/Qt:** ریسک بالا؛ قبل از انتخاب نهایی، نمونه کوچک کامپایل و اجرا شود و فعالیت/نگهداری Binding ارزیابی شود.
2. **فارسی در PDF:** ریسک بالا؛ شکل‌دهی حروف، BiDi، فونت، جدول چندصفحه‌ای و چاپ با نمونه واقعی سنجیده شوند.
3. **دقت مالی:** ریسک بالا؛ واحد پول، ترتیب تخفیف/مالیات و گردکردن پیش از توسعه تثبیت شود.
4. **شماره‌گذاری و پرداخت:** ریسک بالا؛ عملیات باید تراکنشی و در برابر تکرار مقاوم باشد.
5. **نصب و ارتقا:** ریسک متوسط تا بالا؛ آزمایش در Windows تمیز و حفظ داده الزامی است.
6. **مجوز وابستگی‌ها:** ریسک تجاری؛ فهرست وابستگی و مجوزها پیش از انتشار بازبینی شود.
7. **تقویم شمسی:** ریسک متوسط؛ سیاست ذخیره تاریخ، محدوده پشتیبانی و تبدیل‌ها تست شوند.

## گام بعدی
فاز ۱ با جمع‌آوری اطلاعات محیط، بررسی گزینه‌های Binding و مجوزها، و ساخت نمونه حداقلی آغاز می‌شود. هیچ گزینه‌ای صرفاً بر اساس نام یا ادعای مستندات، سازگار اعلام نمی‌شود.
