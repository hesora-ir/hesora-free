# نصب‌کننده ویندوز

## وضعیت و محدوده

نصب‌کننده MSI بر پایه WiX Toolset 6.0.2 است. رابط استاندارد گرافیکی WiX برای نصب تعاملی پیکربندی شده است:

1. صفحه خوش‌آمدگویی و معرفی نصب.
2. نمایش متن کامل مجوز فارسی و گزینه‌های پذیرش/عدم پذیرش؛ ادامه نصب بدون پذیرش مجوز ممکن نیست.
3. انتخاب مسیر نصب از طریق دکمه Browse؛ مسیر پیش‌فرض در Program Files قرار دارد.
4. صفحه مرور تنظیمات و تأیید شروع نصب.
5. نمایش پیشرفت نصب و نتیجه پایان عملیات.
6. ایجاد میان‌بر «Invoice Maker» در منوی Start و Desktop کاربری که نصب را اجرا می‌کند.
7. حذف میان‌برها همراه با Uninstall.

این رفتار با WiX UI استاندارد WixUI_InstallDir پیاده‌سازی شده است. این UI برخلاف Bootstrapper سفارشی، یک رابط MSI استاندارد ویندوز است و ظاهر آن تابع نسخه Windows Installer است.

**محدودیت پذیرش:** فایل MSI باید روی Windows واقعی ساخته و اجرا شود تا چیدمان فارسی، نمایش صحیح RTF، پذیرش اجباری مجوز، انتخاب مسیر، پیشرفت نصب و ایجاد میان‌برها تأیید شوند. این محیط به ماشین Windows کاربر دسترسی اجرایی ندارد؛ بنابراین این مستندات به‌تنهایی اثبات تست عملی نیستند.

## پیش‌نیازهای محیط ساخت

- Windows 10/11 x64
- Go دقیقاً 1.25.1 مطابق سیاست فعلی مخزن
- Qt 6.12.0 با kit سازگار MinGW در مسیر پیش‌فرض G:\qt\6.12.0\mingw_64 یا مسیر تعیین‌شده با -QtRoot / QT_ROOT
- ابزارهای qmake.exe و windeployqt.exe از همان kit Qt
- WiX CLI و SDK نسخه 6.0.2 و .NET SDK
- کامپایلر/ابزارهای C و C++ سازگار با kit Qt و تنظیمات CGO پروژه

اسکریپت نسخه Go، Qt و WiX را بررسی می‌کند و در صورت عدم تطابق متوقف می‌شود. نسخه ابزار به‌تنهایی سازگاری کامل Binding، کامپایلر یا مجوزهای توزیع Qt را اثبات نمی‌کند.

## ساخت MSI

از ریشه مخزن در PowerShell اجرا کنید:

    .\scripts\build-installer.ps1

برای تعیین نسخه محصول یا مسیر Qt:

    .\scripts\build-installer.ps1 -ProductVersion 0.1.0 -QtRoot 'G:\qt\6.12.0\mingw_64'

خروجی مورد انتظار:

    artifacts\installer\HesoraSetup-0.1.0-x64.msi

اسکریپت ابتدا برنامه Go را می‌سازد، سپس windeployqt را با گزینه‌های Release و compiler runtime اجرا می‌کند، فایل‌های assets را در artifacts\publish\assets قرار می‌دهد و وجود executable، Qt DLLها، qwindows.dll، آیکون و فونت‌ها را بررسی می‌کند.

برای رفع خطای مسیر آیکون، مسیر کامل آیکون به‌صورت یک MSBuild property مستقل (PublishIconPath) به WiX داده می‌شود. به مسیر PublishDir با الحاق مستقیم assets اتکا نمی‌شود؛ MSBuild ممکن است جداکننده انتهایی مسیر را حذف کند.

پروژه WiX از افزونه WixToolset.UI.wixext نسخه 6.0.2 استفاده می‌کند. فایل installer\License.rtf متن فارسی مجوز را برای صفحه EULA فراهم می‌کند.

**کدپیج MSI:** ویژگی Package/@Codepage روی 1256 (Windows-1256) تنظیم شده است تا نویسه‌های فارسی موجود در نام محصول، توضیحات و پیام‌های بسته با کدپیج پیش‌فرض 1252 رد نشوند. مقدار زبان بسته نیز 1065 (فارسی) است. Build و نمایش واقعی رشته‌ها در Windows باید تأیید شود؛ تنظیم کدپیج به‌تنهایی تضمین‌کننده ظاهر درست فونت/RTL در تمام Dialogها نیست.

## مراحل و رفتار نصب

- محدوده نصب فعلی perMachine است؛ نصب ممکن است درخواست دسترسی Administrator کند.
- مسیر پیش‌فرض نصب: Program Files\Invoice Maker؛ کاربر می‌تواند آن را در صفحه انتخاب مسیر تغییر دهد.
- صفحه مجوز قبل از انتخاب مسیر نمایش داده می‌شود و گزینه عدم پذیرش مانع ادامه نصب است.
- نصب‌کننده مراحل نصب و نوار پیشرفت MSI را نشان می‌دهد.
- میان‌بر برنامه در Start Menu و Desktop پروفایل کاربری اجراکننده نصب ایجاد می‌شود.
- میان‌برها هنگام حذف برنامه پاک می‌شوند. چون این Shortcutها در پوشه‌های پروفایل کاربر قرار می‌گیرند، هر Component دارای KeyPath مستقل در HKCU است؛ این کار با الزامات ICE38 و ICE43 برای Shortcutهای non-advertised سازگار است. خود فایل‌های برنامه همچنان perMachine نصب می‌شوند. در نتیجه Shortcutها برای کاربری ایجاد می‌شوند که نصب را اجرا کرده است، نه تمام کاربران سیستم.
- بسته MSI با CAB جاسازی‌شده ساخته می‌شود.
- UpgradeCode ثابت و MajorUpgrade برای تشخیص نسخه‌های مرتبط و جلوگیری از Downgrade تنظیم شده است.

## مجوز استفاده

متن حقوقی قابل بازبینی در docs/END_USER_LICENSE_AGREEMENT.md و نسخه RTF نمایش‌داده‌شده در نصب‌کننده در installer/License.rtf نگهداری می‌شود.

اصول کلیدی:
- مجوز استفاده محدود، غیرانحصاری و غیرقابل‌انتقال است؛ مالکیت نرم‌افزار منتقل نمی‌شود.
- توزیع یا فروش مجدد نسخه اختصاصی بدون اجازه کتبی مجاز نیست.
- حقوق کاربران تحت مجوزهای متن‌باز اجزای ثالث محفوظ است.
- صحت اسناد، مبالغ، مالیات و اطلاعات واردشده مسئولیت کاربر است.
- کاربر مسئول تهیه نسخه پشتیبان از داده‌های خود است.
- سلب ضمانت و محدودیت مسئولیت فقط تا حد مجاز قانون اعمال می‌شود و حقوق آمره را حذف نمی‌کند.

این متن یک پیش‌نویس محصول است، نه مشاوره حقوقی. پیش از انتشار یا فروش عمومی باید توسط مشاور حقوقی آشنا با بازار و حوزه قضایی عرضه بررسی شود. اطلاعات تماس یا قانون حاکم خاصی بدون تعیین رسمی در متن درج نشده است.

## داده‌های کاربر

- پایگاه داده و تنظیمات نباید در پوشه نصب ذخیره شوند.
- مسیر پایگاه داده برنامه در %LOCALAPPDATA%\invoice-maker\invoice-maker.db است.
- حذف MSI نباید پایگاه داده کاربر را حذف کند.
- داده‌های کاربر باید در ارتقا حفظ شوند؛ این رفتار نیازمند تست عملی نصب/ارتقا/حذف روی Windows است.

## بررسی اولیه MSI

پس از ساخت:

    .\scripts\test-installer.ps1 -MsiPath '.\artifacts\installer\HesoraSetup-0.1.0-x64.msi'

این بررسی جدول فایل‌ها، Dialogهای رابط نصب (از جمله صفحه مجوز و انتخاب مسیر) و میان‌برهای Desktop/Start Menu را از MSI می‌خواند. این آزمون، نصب واقعی، اجرای برنامه یا تست ارتقا را جایگزین نمی‌کند.

## چک‌لیست پذیرش در ماشین مجازی تمیز

روی Windows 10 و Windows 11 x64 که Qt، Go و ابزار توسعه نصب نیستند:

1. MSI را با دوبار کلیک اجرا کنید؛ مطمئن شوید رابط گرافیکی و صفحه خوش‌آمدگویی ظاهر می‌شود.
2. متن مجوز فارسی را بررسی کنید. «نمی‌پذیرم» را انتخاب کنید و مطمئن شوید نصب ادامه نمی‌یابد.
3. دوباره اجرا کنید؛ «می‌پذیرم» را انتخاب کنید و ادامه دهید.
4. مسیر نصب را از مسیر پیش‌فرض به یک پوشه آزمایشی تغییر دهید؛ فایل‌ها باید دقیقاً همان‌جا نصب شوند.
5. نوار پیشرفت و صفحه پایان نصب را بررسی کنید.
6. وجود میان‌بر در Desktop و منوی Start را بررسی و هر دو را اجرا کنید.
7. برنامه را باز کنید؛ وجود DLLهای Qt و runtime کامپایلر را تأیید کنید.
8. یک رکورد آزمایشی بسازید، سپس MSI نسخه بالاتر را نصب کنید؛ برنامه ارتقا یافته و رکورد قبلی باید باقی بماند.
9. از Apps/Programs حذف کنید؛ فایل‌های برنامه و میان‌برها باید حذف شوند اما داده‌های کاربر باقی بمانند.
10. نصب مجدد را با دیتابیس موجود آزمایش کنید.
11. نصب نسخه پایین‌تر از نسخه بالاتر باید مسدود شود.
12. نتیجه و نسخه Windows/Qt/Go/WiX را بدون اطلاعات شخصی یا بانکی ثبت کنید.

تا زمان اجرای این چک‌لیست، Installer برای انتشار تجاری تأییدشده نیست.

## محدودیت‌ها و امنیت

- رابط استفاده‌شده UI استاندارد MSI است؛ Bootstrapper اختصاصی و برندشده ساخته نشده است.
- نصب تعاملی از طریق MSI UI مجوز را پیش از ادامه می‌خواهد؛ اجرای کاملاً بی‌صدا با ‎/qn‎ رابط را نمایش نمی‌دهد و در این فاز سیاست پذیرش مستقل برای نصب بی‌صدا تعریف نشده است. معیار پذیرش این نسخه اجرای معمولی با دوبار کلیک است.
- بسته NuGet مربوط به WixToolset.UI.wixext نسخه 6.0.2 در صفحه رسمی خود Open Source Maintenance Fee را برای استفاده درآمدزا اعلام می‌کند؛ پیش از انتشار تجاری، EULA و تعهد مالی آن باید بررسی و رعایت شود: https://www.nuget.org/packages/WixToolset.UI.wixext/6.0.2
- امضای دیجیتال MSI و فایل اجرایی، اعتبارسنجی ناشر و انتشار امن هنوز پیکربندی نشده‌اند.
- مجوزهای توزیع Qt، MinGW و فونت‌های تعبیه‌شده باید قبل از انتشار بررسی شوند.
- MSI به‌تنهایی Backup/Restore ایجاد نمی‌کند.
- نصب/ارتقا/حذف روی Windows clean-VM باید قبل از انتشار عملی آزمایش شود.
