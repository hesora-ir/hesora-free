# اعتبارسنجی آفلاین اطلاعات بانکی ایران

هستهٔ مستقل Go در `internal/banking` بدون شبکه/API قابل استفاده است.

- `NormalizeBankNumber`: تبدیل رقم‌های فارسی/عربی به لاتین و حذف فاصله و خط تیره.
- `ValidateCard`: طول ۱۶ رقم، Luhn و تشخیص بانک از پیشوندهای همراه برنامه.
- `ValidateIBAN`: ساختار شبای ایران و کنترل MOD-97؛ کد بانک از بخش شبای ایران خوانده می‌شود.
- `ValidateAccount`: بررسی صرفاً ساختاریِ عددی و طول عمومی ۴ تا ۳۰ رقم.
- `ConvertAccountToIBAN`: در حال حاضر عمداً `CONVERSION_UNAVAILABLE` می‌دهد.

اعتبار checksum نشان‌دهندهٔ وجود حساب یا مالکیت آن نیست. قاعدهٔ واحدی برای طول/ساختار همهٔ شماره‌حساب‌های بانکی وجود ندارد؛ تا وقتی قواعد اختصاصی یک بانک و نوع حساب از مرجع معتبر و نمونه‌های کافی بررسی نشده باشند، این کتابخانه شماره‌حساب را صرفاً از نظر قالب عمومی می‌سنجد و از روی آن شبا تولید نمی‌کند. فهرست پیشوندهای کارت و کدهای شبا داخلی است و باید با تغییرات رسمی بانک‌ها بازبینی شود.
