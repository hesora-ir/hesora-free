# اتصال نسخهٔ رایگان به وب هسورا

سرویس متناظر PHP 8.4 در پروژهٔ `hesora-web` قرار دارد. نشانی تولید `https://hesora.ir` است. برای ارسال رمز، لایسنس و داده از HTTP عمومی استفاده نمی‌شود. HTTP فقط روی loopback برای توسعه پذیرفته است.

## استفاده در برنامه

در تنظیمات، بخش «بکاپ و اتصال به فضای ابری»:

1. «ساخت حساب و مدیریت بکاپ‌ها در پنل وب» را بزنید و در وب حساب بسازید.
2. با ایمیل و رمز همان حساب در برنامه وارد شوید. توکن فقط در حافظه است و وارد بکاپ SQLite نمی‌شود.
3. برای دریافت Pro، شناسهٔ نصب را از تنظیمات کپی کرده و به مدیر بدهید. مدیر برای حساب شما و همین شناسه، لایسنس مدت‌دار صادر می‌کند.
4. کد را از پنل وب کپی کنید و در «فعال‌سازی لایسنس پرو» وارد کنید. امضای Ed25519، شناسهٔ نصب، محصول و زمان اعتبار بررسی می‌شوند.
5. «بکاپ‌گیری ابری» snapshot سازگار با WAL می‌سازد، سلامت آن را بررسی و همراه SHA256 ارسال می‌کند. فهرست، دانلود و حذف بکاپ‌ها در پنل وب است.
6. «ذخیره بکاپ روی حافظه کامپیوتر» بدون ورود و اشتراک قابل استفاده است. مقصد باید فایل جدید باشد؛ برای حفاظت از اطلاعات، فایل موجود بازنویسی نمی‌شود.

سقف سرویس اولیه برای هر حساب: ۲۰ بکاپ، هرکدام ۵۰ MiB و مجموع ۲۵۰ MiB. بکاپ ابری برای حساب رایگان دارای خدمات ابری نیز قابل استفاده است. دانلود بکاپ‌های قبلی با انقضای Pro بسته نمی‌شود.

## ساخت برنامه با کلید معتبر

کلید خصوصی فقط در سرور باقی می‌ماند. کلید عمومی نمایش‌داده‌شده در پایان نصب وب، یا خروجی `php bin/console.php public-key` روی سرور نصب‌شده را در محیط build تنظیم کنید. فرمان keygen یک جفت جدید و مستقل می‌سازد و جایگزین دریافت کلید فعلی سرور نیست:

```powershell
$env:HESORA_LICENSE_PUBLIC_KEY = 'BASE64URL_ED25519_PUBLIC_KEY'
go build -trimpath "-ldflags=-H=windowsgui -X main.hesoraLicensePublicKeyBase64=$env:HESORA_LICENSE_PUBLIC_KEY" -o build/invoice-maker.exe ./cmd/invoice-maker
```

CMake نیز از متغیر محیط یا `-DHESORA_LICENSE_PUBLIC_KEY=...` و اسکریپت نصب‌کننده از متغیر محیط استفاده می‌کند. در CMake مقدار در cache می‌ماند؛ هنگام تغییر کلید، گزینهٔ `-D` را صریح بدهید. build بدون کلید عمومی همچنان نسخهٔ رایگان است و فعال‌سازی Pro را نمی‌پذیرد.

## قرارداد و محدودیت‌ها

کلاینت `internal/cloud` از `/api/v1/auth/login`، `/me`، `/licenses/validate`، `/backups` و `/cloud/documents` استفاده می‌کند. درخواست‌های شبکه و snapshot در goroutine اجرا می‌شوند و نتیجه روی نخ رابط Qt اعمال می‌شود. نشست‌ها پس از ۲۴ ساعت به ورود دوباره نیاز دارند.

API اسناد، نسخه‌گذاری خوش‌بینانه و tombstone دارد؛ نوشتن نیازمند Pro است. هنوز همگام‌سازی خودکار جداول حسابداری و رابط حل تعارض ارائه نمی‌شود. بکاپ ابری یک snapshot کامل پایگاه داده است و با همگام‌سازی رکوردی تفاوت دارد. بازیابی خودکار روی پایگاه دادهٔ باز برنامه نیز وجود ندارد؛ فایل دانلودی را بدون نگهداری نسخهٔ فعلی روی اطلاعات فعال جایگزین نکنید.

لغو سرور با «بررسی آنلاین اعتبار لایسنس» در برنامه اعمال می‌شود. اعتبار آفلاین تا تاریخ پایان امضا قابل بررسی است؛ لغو فوری در قطع اینترنت تضمین نمی‌شود. انقضا محدودیت‌های رایگان را برمی‌گرداند و داده را حذف نمی‌کند.

## آزمون

```powershell
go test ./internal/...
go vet ./internal/...
# از ریشهٔ پروژهٔ وب؛ پایگاه داده و سرور موقت:
# ابتدا اتصال MySQL و Redis آزمایشی را طبق docs/OPERATIONS.md پروژهٔ وب تنظیم کنید.
$env:HESORA_DESKTOP_DIR = 'C:\Users\hessam\Documents\GitHub\hesora-free'
python tests/http_test.py
```

تست `TestPHPContract` ورود واقعی Go به PHP، پذیرش امضای لایسنس PHP توسط Go، snapshot، آپلود و دریافت متادیتای بکاپ و API سند را بررسی می‌کند.

اصلاح شبا شامل ارقام فارسی/عربی، پیشوند IR، فاصله و نشانه‌های جهت متن است. checksum معتبر بازنویسی یا حدس زده نمی‌شود. در خروجی‌های قدیمی نام بانک از شبای معتبر استخراج می‌شود، اما نام ثبت‌شدهٔ تاریخی حفظ می‌شود.
