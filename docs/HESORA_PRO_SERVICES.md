# سرویس‌های آنلاین Hesora Pro

## وضعیت

جدول مقایسه، فعال‌سازی لایسنس و اتصال به API وب در برنامه وجود دارد. مشتری پس از ثبت‌نام و خرید، فقط کد را در برنامه وارد می‌کند؛ برنامه کلید عمومی را از endpoint HTTPS می‌گیرد و کد را خودکار به نصب فعلی متصل می‌کند. کلاینت با Ed25519 امضای توکن را بررسی می‌کند و قابلیت `pro.full` را فعال می‌سازد. کلید عمومی دیگر هنگام build به مشتری داده نمی‌شود؛ کلید خصوصی فقط روی سرور نگهداری می‌شود.

سرویس وب شامل حساب کاربری، صدور و اعتبارسنجی لایسنس، فهرست/بارگذاری/دانلود/حذف بکاپ و API اسناد ابری است. برنامهٔ دسکتاپ ورود، مشاهدهٔ وضعیت حساب و لایسنس، اعتبارسنجی آنلاین و مدیریت بکاپ را پشتیبانی می‌کند. همگام‌سازی خودکار داده‌های حسابداری، حل تعارض چنددستگاهی، اعلان‌ها و توزیع امن به‌روزرسانی هنوز نیازمند پیاده‌سازی هستند. درگاه پرداخت باید جداگانه پیکربندی و به جریان صدور لایسنس متصل شود.

## وضعیت فعلی و موارد باقی‌مانده

API فعال‌سازی و کلید عمومی زیر `/api/v1` روی HTTPS ارائه می‌شوند. سایت ثبت‌نام دارد و حساب کاربر محل تحویل کد و مدیریت بکاپ‌هاست. درگاه پرداخت و پلن/قیمت هنوز باید به سایت متصل شوند. همگام‌سازی خودکار جداول حسابداری، حل تعارض، اعلان‌ها و توزیع امن به‌روزرسانی نیز باقی مانده‌اند:

- اتصال پرداخت موفق به صدور و نمایش کد یک‌بارمصرف در حساب مشتری.
- صفحهٔ مدیریت فعال‌سازی/انتقال مجوز برای نصب دیگر.
- قرارداد همگام‌سازی دوطرفهٔ اطلاعات محلی با نسخهٔ وب، شامل revision و حل تعارض چند دستگاه.
- manifest به‌روزرسانی امضاشده شامل نسخه، حداقل نسخهٔ سازگار، اندازه و SHA-256 بسته؛ بسته نیز باید امضای قابل‌اعتبارسنجی داشته باشد.
- اعلان‌های کاربر با شناسهٔ یکتا، زمان انتشار و قابلیت علامت‌گذاری به‌عنوان خوانده‌شده.
- رمزنگاری سمت کاربر، زمان‌بندی، سیاست نگهداری و بازیابی امن بکاپ‌ها.

## سیاست داده و نگهداری

دسترسی وب به فاکتورها برای ۲ سال باید بر اساس زمان خرید/انقضای پلن در سرور کنترل شود. پیش از ارسال دادهٔ مشتری و فاکتور به سرور، قالب snapshot، رمزنگاری در مقصد، جداسازی دادهٔ هر حساب، محل نگهداری، حذف حساب و رویهٔ بازیابی باید تعیین شوند. پشتیبان‌گیری خودکار نباید جایگزین امکان دریافت فایل پشتیبان محلی شود.

## اطلاعات لازم برای فعال‌کردن سرویس واقعی

1. درگاه پرداخت، انواع پلن و قیمت.
2. سیاست فعال‌سازی مجدد یا انتقال مجوز به رایانهٔ دیگر.
3. سیاست همگام‌سازی، تعارض، نگهداری دوساله و حذف داده.
4. قالب manifest، کلید امضای به‌روزرسانی و کانال انتشار.
5. تناوب، حجم، رمزنگاری و زمان نگهداری پشتیبان ابری.
