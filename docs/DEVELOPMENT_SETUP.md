# آماده‌سازی محیط توسعه

## محیط هدف اعلام‌شده
- Windows 10/11
- Go 1.25.1
- Qt 6.12.0، مسیر G:\qt\6.12.0\mingw_64
- WiX Toolset 6.0.2+b3f3403
- MinGW، CMake و Ninja: نسخه‌ها هنوز باید بررسی شوند

این فهرست مشخصات موردنظر است، نه تأیید نصب بودن ابزارها. در فاز صفر امکان اجرای فرمان‌ها در محیط محلی Windows در دسترس نبود؛ ازاین‌رو خروجی نسخه‌ها ثبت نشده است.

## بررسی‌های لازم در Windows
PowerShell را باز کنید و فرمان‌های زیر را اجرا کنید:

    go version
    go env
    where.exe go
    cmake --version
    ninja --version
    where.exe cmake
    where.exe ninja
    where.exe gcc
    gcc --version
    where.exe wix
    wix --version

برای Qt، مسیر اعلام‌شده و ابزارهای همراه را بررسی کنید:

    Test-Path 'G:\qt\6.12.0\mingw_64'
    Get-ChildItem 'G:\qt\6.12.0\mingw_64' -ErrorAction SilentlyContinue

نسخه Qt را از فایل‌های نصب/ابزارهای رسمی همان نصب بررسی کنید؛ صرف وجود پوشه اثبات سازگاری نیست. مطمئن شوید MinGW انتخاب‌شده با بسته Qt هم‌خوان است.

## قبل از توسعه
1. خروجی نسخه‌ها و PATH را ثبت کنید.
2. وضعیت مجوز Qt و Binding منتخب را بررسی کنید.
3. یک نمونه حداقلی Go/Qt بسازید و روی Windows اجرا کنید.
4. فرآیند Build را در یک محیط تمیز تکرار کنید.
5. ابزارها را بدون ثبت اطلاعات حساس در مخزن مستند کنید.

## سیاست وابستگی
- نسخه‌ها صریح و قابل بازتولید باشند.
- وابستگی‌ها و مجوزهای توزیع تجاری بررسی شوند.
- از تغییر نسخه/مسیر اعلام‌شده بدون ثبت دلیل و آزمون خودداری شود.
- تا پیش از نمونه موفق، Binding یا دستور Build قطعی معرفی نشود.


## SQLite فاز ۲

- درایور آزمایشی SQLite: `modernc.org/sqlite v1.39.1`، مبتنی بر Go خالص برای اجتناب از وابستگی CGO اضافی در لایه دیتابیس.
- پس از دریافت وابستگی‌ها، در محیط Go 1.25.1 اجرا کنید:

      go mod tidy
      go test ./internal/domain ./internal/adapters/sqlite ./internal/platform/datadir

- برای بررسی کل ماژول، نمونه Qt نیز به toolchain سازگار Qt/MinGW نیاز دارد؛ اجرای `go test ./...` را در محیطی انجام دهید که Qt و CGO برای MIQT تنظیم شده‌اند.
- مسیر داده ویندوز `%LOCALAPPDATA%\\invoice-maker\\invoice-maker.db` است. پوشه Hidden می‌شود تا کمتر در Explorer دیده شود؛ این ویژگی جایگزین Backup نیست و حذف را ناممکن نمی‌کند.
