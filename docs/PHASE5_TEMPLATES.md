# فاز ۵ — قالب‌ها، سربرگ و پیش‌نمایش

## پیاده‌سازی
- مدل‌های اعتبارسنجی‌شده برای قالب سند، سربرگ و حساب بانکی.
- Migration شماره ۴ برای ذخیره سربرگ‌ها، حساب‌ها، قالب‌ها و ارتباط قالب با حساب‌ها.
- عملیات SQLite برای ایجاد/ویرایش و فهرست‌کردن سربرگ، حساب بانکی و قالب.
- ذخیره قالب و ارتباط حساب‌های منتخب در تراکنش واحد.
- سرویس Application برای مدیریت قالب‌ها و تولید پیش‌نمایش.
- renderer مستقل HTML با RTL، اندازه صفحه، رنگ، فونت، سربرگ، جدول اقلام، جمع‌های مالی و اطلاعات پرداخت.
- تست‌های واحد و SQLite برای اعتبارسنجی، escape و ذخیره‌سازی.
