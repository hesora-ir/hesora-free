# سیستم قالب، سربرگ و پیش‌نمایش

## اجزا
- `DocumentTemplate`: اندازه صفحه A4/Letter، حالت عمودی/افقی، فونت، اندازه متن، رنگ اصلی/تأکیدی، سربرگ انتخابی، حساب‌های بانکی منتخب و نمایش/عدم نمایش لوگو، مالیات و اطلاعات پرداخت.
- `Letterhead`: عنوان، زیرعنوان، مسیر محلی لوگو و خط اطلاعات تماس؛ قابلیت اتصال به پروفایل صادرکننده دارد.
- `BankAccount`: نام بانک، صاحب حساب، شماره حساب، کارت و شبا؛ حساب‌ها در پایگاه داده محلی ذخیره می‌شوند.
- `template_bank_accounts`: ترتیب حساب‌های بانکی مرتبط با هر قالب را ثبت می‌کند.
- `internal/render/html`: HTML پیش‌نمایش را از مدل سند، اقلام و خروجی مشترک محاسبات مالی تولید می‌کند.

## قواعد امنیت و صحت
- نام فونت و رنگ‌ها اعتبارسنجی می‌شوند؛ رنگ فقط به صورت #RRGGBB پذیرفته می‌شود.
- محتوای مشتری، صادرکننده، شرح قلم، یادداشت و اطلاعات بانکی پیش از درج در HTML escape می‌شود.
- مسیر لوگو باید مسیر محلی انتخاب‌شده توسط کاربر باشد؛ URLهای راه دور در رندر لوگو پذیرفته نمی‌شوند.
- مبلغ‌ها در renderer دوباره محاسبه مستقل نمی‌شوند؛ جمع‌ها از `domain.CalculateFinancials` گرفته می‌شوند و مبلغ هر قلم از `InvoiceItem.LineTotal`.
- اسناد از snapshot مشتری و صادرکننده استفاده می‌کنند تا تغییر پروفایل فعلی، اطلاعات تاریخی سند را تغییر ندهد.

## ذخیره‌سازی
Migration شماره ۴ جدول‌های `issuer_letterheads`، `bank_accounts`، `document_templates` و `template_bank_accounts` را اضافه می‌کند. حساب‌های بانکی و سربرگ‌ها به صورت رکوردهای مستقل هستند؛ هر قالب می‌تواند به یک سربرگ و چند حساب بانکی متصل شود.

## وضعیت و محدودیت‌ها
- ذخیره‌سازی CRUD اولیه و تولید HTML RTL برای پیش‌نمایش اضافه شده است.
- تست‌های واحد برای اعتبارسنجی قالب، escape محتوا و تست‌های SQLite برای ذخیره‌سازی نوشته شده‌اند؛ اجرای واقعی آن‌ها هنوز تأیید نشده است.
- نمایش تعاملی پیش‌نمایش در پنجره Qt، انتخاب فایل لوگو از دیالوگ سیستم، و ویرایش قالب/سربرگ/حساب بانکی در UI هنوز متصل نشده‌اند.
- HTML پیش‌نمایش خروجی نهایی PDF نیست؛ PDF و XLSX در فاز ۶ پیاده‌سازی می‌شوند.
- اعداد و تاریخ‌ها در پیش‌نمایش فعلاً با قالب عددی/ISO ذخیره‌شده نمایش داده می‌شوند؛ بومی‌سازی کامل ارقام و تاریخ شمسی باید پس از تثبیت تقویم تکمیل شود.
