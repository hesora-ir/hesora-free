# وضعیت واقعی شاخه main — بازبینی ۲۵ اکتبر ۲۰۲۶

## خلاصه

این سند وضعیت فعلی شاخه `main` را بر اساس فایل‌های قابل مشاهده در GitHub ثبت می‌کند. این بازبینی فقط بررسی مخزن راه‌دور است؛ Build ویندوز، اجرای Qt، تست‌های Go و ساخت/نصب MSI در این نشست اجرا نشده‌اند. وجود کد یا تست به معنی موفقیت اجرای آن نیست.

## فایل‌ها و قابلیت‌های موجود در main

- ماژول Go با نسخه اعلام‌شده `go 1.25.1` و وابستگی‌های MIQT، SQLite، PDF و XLSX در `go.mod`.
- رابط Qt فارسی/RTL با داشبورد و بخش‌های مشتریان، اطلاعات پایه، تنظیمات، صدور فاکتور و فهرست فاکتورها.
- لایه‌های Domain و Application و آداپتر SQLite با migrationهای نسخه‌بندی‌شده.
- گردش‌های اولیه فاکتور، محاسبات مالی، پرداخت/تخصیص، تقویم، قالب‌ها و رندر پیش‌نمایش.
- بسته‌های خروجی PDF و Excel و ماژول لایسنس.
- `CMakeLists.txt` و `docs/CMAKE_DEVELOPMENT.md` برای ساخت/اجرای توسعه‌ای با CMake.
- `installer/InvoiceMaker.wxs`, `installer/InvoiceMaker.wixproj`, `scripts/build-installer.ps1` و `scripts/test-installer.ps1`.
- اصلاح‌های UI برای APIهای MIQT و مسیر میان‌بر Start Menu سازگار با نصب per-machine.

تغییرات رابط کاربری و CMake در PRهای #22 و #23 ادغام شده‌اند؛ اصلاحات خطاهای Build/تست، پرداخت تکراری و WiX نیز در PRهای #16، #17، #18 و #19 ادغام شده‌اند.

## محدودیت‌های مهمی که همچنان باز هستند

- فرم صدور فاکتور و صفحه فهرست فاکتورها در UI هنوز چیدمان اولیه‌اند و نباید به‌عنوان جریان کامل عملیاتی معرفی شوند.
- شاخص‌های داشبورد عمداً placeholder هستند و به آمار مالی واقعی متصل نیستند.
- Build و اجرای Qt با ترکیب واقعی Go/Qt/MinGW روی Windows هنوز باید با نتیجه قابل مشاهده تأیید شود.
- تست‌های Go، `go vet` و وضعیت CI باید روی commit فعلی بررسی شوند؛ این بازبینی نتیجه سبز را تأیید نمی‌کند.
- PDF/XLSX باید از نظر فارسی/RTL، شکل‌دهی حروف، فونت، صفحه‌بندی، تاریخ شمسی و چاپ روی Windows آزمایش شوند.
- Installer باید با WiX 6.0.2 ساخته و روی Windows تمیز از نظر نصب، ارتقا، جلوگیری از downgrade، حذف و حفظ داده آزمایش شود.
- Backup/Restore، سیاست نگهداری داده و امنیت/مجوزهای توزیع وابستگی‌ها نیازمند آزمون و مستندات پذیرش‌اند.
- لایسنس آفلاین به‌تنهایی در برابر patch برنامه یا دستکاری ساعت تضمین کامل ایجاد نمی‌کند؛ داده‌های کاربر نباید به‌دلیل انقضای لایسنس قفل شوند.

## ناسازگاری نسخه ابزار

در `go.mod` نسخه Go برابر `1.25.1` است و مشخصات محیط پروژه نیز همین نسخه را تعیین می‌کند. اسکریپت Installer باید همین نسخه را بررسی کند تا پیش‌نیاز آن با ماژول Go یکسان باشد. Qt هدف `6.12.0) MinGW و WiX هدف `6.0.2` باقی می‌مانند.

## نتیجه مقایسه شاخه‌ها

شاخه `main` تغییرات اصلی UI، CMake، هسته داده/مالی، خروجی‌ها، لایسنس و Installer را در تاریخچه فعلی خود دارد. اختلاف‌های قدیمی شاخه‌های اصلاح WiX با نسخه نهایی موجود در `main` جایگزین شده‌اند. پیش از ادغام هر تغییر جدید، باید ابتدا `main` با SHA دقیق و diff شاخه مقایسه شود؛ از ادغام دوباره تغییرات تاریخی یا merge خودکار اجتناب کنید.

## چک‌لیست پذیرش باقی‌مانده

1. روی Windows با Go 1.25.1، Qt 6.12.0/MinGW و CMake نسخه 3.25 یا بالاتر اجرا کنید: `go test ./...`, `go vet ./...`, `gofmt -l .` و `cmake --build build --target run-app`.
2. Build و اجرای واقعی UI و اتصال سناریوی مشتری تا صدور فاکتور و ثبت پرداخت را بررسی کنید.
3. PDF/XLSX فارسی و چندصفحه‌ای را با مقادیر نمونه کنترل‌شده بررسی کنید.
4. MSI را بسازید و نصب/ارتقا/حذف/نصب مجدد را روی Windows 10/11 تمیز آزمایش کنید.
5. نتیجه‌ها را با SHA کامیت، نسخه ابزار و log بدون اطلاعات شخصی/بانکی ثبت کنید.

تا وقتی این معیارها با نتایج واقعی تأیید نشده‌اند، پروژه را آماده انتشار تجاری اعلام نکنید.
