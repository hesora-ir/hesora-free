# راهنمای تنظیمات

این راهنما رفتار تنظیمات ظاهری و پیش‌فرض‌های عمومی نسخه فعلی برنامه را ثبت می‌کند.

## فونت رابط کاربری

از تب «تنظیمات» می‌توان یکی از فونت‌های زیر را انتخاب کرد:

- IRANSansX
- IRANSharp
- IRAN Family Typeface
- IRAN Kharazmi
- IRANMarker
- Segoe UI (سیستم)
- Tahoma (سیستم)

فونت‌های همراه برنامه از مسیرهای زیر بارگذاری می‌شوند:

- `assets/font/iransans/IRANSansX-Regular.ttf`
- `assets/font/IRANSharp/IRANSharpRegular.ttf`
- `assets/font/IRAN Family Typeface/IRAN(FaNum).ttf`
- `assets/font/IRAN_Kharazmi/IRAN Kharazmi.ttf`
- `assets/font/iranmarker/IRANMarker.ttf`

اندازه فونت رابط بین ۸ تا ۳۲ پوینت قابل تنظیم است. این انتخاب به فونت عمومی Qt و stylesheet پنجره اصلی اعمال می‌شود. بخش‌هایی از UI که stylesheet اختصاصی دارند ممکن است همچنان اندازه/رنگ مختص خود را حفظ کنند.

## قالب رنگ

- «روشن»: قالب روشن برنامه.
- «تیره»: قالب تیره پایه برای پنجره و کنترل‌های عمومی.
- «سیستمی»: در این نسخه به قالب روشن برمی‌گردد؛ تشخیص خودکار ترجیح رنگ سیستم هنوز پیاده‌سازی نشده است.

## آیکون برنامه

با «انتخاب فایل آیکون…» فایل محلی با فرمت ICO، PNG یا SVG انتخاب می‌شود. «بازنشانی آیکون» فیلد را خالی می‌کند تا آیکون پیش‌فرض `assets/invoice-maker.ico` استفاده شود.

تنظیم `app_icon_path` فقط مسیر محلی فایل را در SQLite ذخیره می‌کند؛ خود فایل به پوشه داده کاربر کپی نمی‌شود. اگر مسیر سفارشی در رایانه دیگری وجود نداشته باشد، آن فایل قابل استفاده نخواهد بود. آیکون سفارشی پنجره برنامه را تغییر می‌دهد، اما جایگزینی آیکون جاسازی‌شده در فایل EXE یا آیکون میانبر MSI از داخل برنامه انجام نمی‌شود.

## پیش‌فرض پول

گزینه «تومان (IRT)» یا «ریال (IRR)» مقدار `default_currency` را ذخیره می‌کند تا فرم‌های فاکتور بتوانند آن را به عنوان پیش‌فرض مصرف کنند. در نسخه فعلی فرم صدور فاکتور هنوز به منطق تجاری کامل متصل نشده است؛ بنابراین انتخاب این گزینه به تنهایی محاسبات یا اسناد موجود را بازنویسی نمی‌کند.

## مجوز نرم‌افزار

بخش مجوز در حال حاضر فقط پیام «فعال‌سازی لایسنس — به‌زودی» را نمایش می‌دهد. واردکردن، ذخیره‌کردن یا اعتبارسنجی لایسنس در این رابط پیاده‌سازی نشده است و نباید این وضعیت را فعال‌سازی واقعی تلقی کرد.

## ذخیره‌سازی و کلیدها

تنظیمات در جدول `settings` پایگاه داده محلی ذخیره می‌شوند. کلیدهای مورد استفاده رابط:

| کلید | کاربرد |
|---|---|
| `default_currency` | `IRT` یا `IRR` |
| `theme` | `light`، `dark` یا `system` |
| `font_family` | نام فونت منتخب |
| `font_size` | اندازه فونت در بازه ۸ تا ۳۲ |
| `app_icon_path` | مسیر محلی آیکون سفارشی؛ مقدار خالی یعنی آیکون پیش‌فرض |

## اعتبارسنجی نسخه انتشار

در محیط توسعه، از ریشه مخزن اجرا شود:

```powershell
go test ./...
go vet ./...
gofmt -l .
.`scripts\build-installer.ps1`
```

Build و تست رابط Qt باید روی Windows با Go 1.25.1 و Qt 6.12.0/MinGW انجام شود. تا پیش از اجرای واقعی این فرمان‌ها و بررسی دستی راست‌به‌چپ، فونت‌ها، رنگ تیره، انتخاب آیکون، نصب و اجرای روی ماشین تمیز، این بخش برای انتشار تأییدشده محسوب نمی‌شود.
