# فاز ۳ — رابط پایه، مشتریان، صادرکننده و تنظیمات

## ورودی برنامه

ورودی رابط اصلی در `cmd/invoice-maker/main.go` قرار دارد. برنامه قبل از ساخت پنجره، SQLite را از مسیر داده محلی کاربر باز می‌کند؛ سپس جهت کلی رابط را RTL تنظیم می‌کند.

## بخش‌ها

### مشتریان
- ثبت نام، تلفن، ایمیل و نشانی مشتری
- جست‌وجو بر اساس نام، تلفن یا ایمیل
- فهرست محدود به ۵۰۰ نتیجه برای جلوگیری از بارگذاری نامحدود
- اعتبارسنجی در Domain/Application و استفاده از پارامترهای SQL

در این مرحله فرم ویرایش انتخاب‌شده در UI هنوز وجود ندارد؛ عملیات Update در لایه ذخیره‌سازی پیاده‌سازی شده است و اتصال آن به فرم در ادامه تکمیل می‌شود.

### صادرکننده
- ثبت چند پروفایل با نام، نام حقوقی، شناسه مالیاتی، تلفن، ایمیل و نشانی
- نمایش فهرست پروفایل‌های ثبت‌شده
- عملیات به لایه Application و SQLite متصل است.

در این مرحله انتخاب پروفایل به‌عنوان پیش‌فرض و ویرایش پروفایل از رابط هنوز تکمیل نشده است.

### تنظیمات
- واحد پول پیش‌فرض: `IRT` یا `IRR`
- قالب رنگ ذخیره‌شونده: `system`، `light` یا `dark`
- اندازه فونت ذخیره‌شونده: عدد ۸ تا ۳۲
- مقادیر در جدول `settings` ذخیره می‌شوند و در اجرای بعدی خوانده می‌شوند.

تنظیمات رنگ و فونت فعلاً ذخیره می‌شوند؛ اعمال کامل آن‌ها به تمام ویجت‌ها و پشتیبانی از تنظیمات نمایشی پیشرفته در این فاز نهایی نشده است.

## جداسازی لایه‌ها

رابط Qt منطق SQL را مستقیم اجرا نمی‌کند؛ درخواست‌ها را به `internal/application` می‌دهد. اعتبارسنجی اصلی در Domain/Application است. لایه SQLite از queryهای پارامتری استفاده می‌کند.

## معیارهای باز
- اجرای Build و `go test` با Go 1.25.1 و Qt 6.12/MinGW هدف
- بررسی عملی RTL، متن ترکیبی فارسی/لاتین، صفحه‌کلید و نمایشگرهای مختلف
- فرم ویرایش/آرشیو مشتری و انتخاب مشتری از جدول
- ویرایش و انتخاب پروفایل صادرکننده
- اعمال واقعی قالب رنگ و اندازه فونت
- بررسی خطاهای SQLite و تجربه کاربری روی Windows

این تغییر، رابط پایه است؛ نباید به‌عنوان رابط محصول نهایی معرفی شود.
