# توسعه سریع با CMake

این پروژه از Go و MIQT (Bindingهای Qt برای Go) استفاده می‌کند؛ بنابراین CMake در این مخزن **هماهنگ‌کننده Build** است و کد Go را به‌عنوان C++ کامپایل نمی‌کند.

## پیش‌نیازها در ویندوز

- CMake نسخه 3.25 یا جدیدتر
- Go سازگار با نسخه درج‌شده در `go.mod`
- Qt 6.12.0 با کیت MinGW در مسیر پیش‌فرض `G:/qt/6.12.0/mingw_64` یا مسیر دلخواه
- `windeployqt.exe` در پوشه `bin` همان کیت Qt

## ساخت و اجرای بدون نصب مجدد

از پوشه ریشه مخزن در PowerShell اجرا کنید:

```powershell
cmake -S . -B build -DQT_ROOT="G:/qt/6.12.0/mingw_64"
cmake --build build --target run-app
```

برای ساخت بدون اجرا:

```powershell
cmake --build build --target build-app
```

فایل اجرایی و DLLهای Qt در `build/bin/` قرار می‌گیرند. هر بار که فایل‌های Go تغییر کنند، اجرای دوباره هدف `run-app` برنامه را در همان پوشه Build بازسازی و اجرا می‌کند؛ نیازی به ساخت MSI یا نصب مجدد برنامه نیست. Buildهای Go از Cache کامپایلر استفاده می‌کنند.

برای توسعه روزمره، اجرای مستقیم از پوشه Build توصیه می‌شود. اسکریپت `scripts/build-installer.ps1` همچنان برای تولید بسته نصب قابل توزیع است.

## نکات

- مسیر Qt را می‌توان هنگام Configure با `-DQT_ROOT="مسیر"` تغییر داد.
- در ویندوز، خروجی با زیرسیستم GUI ساخته می‌شود تا پنجره کنسول جداگانه نمایش داده نشود.
- این تنظیم فقط پنجره کنسول را پنهان می‌کند؛ برای خطاهای زمان اجرا از گزارش‌گیری یا پنجره خطای برنامه استفاده کنید.
- CMake/Build/اجرای Qt باید روی سیستم ویندوز دارای Go و Qt نصب‌شده آزمایش شود؛ این تغییر به‌تنهایی ادعای موفقیت Build یا اجرای واقعی ندارد.
