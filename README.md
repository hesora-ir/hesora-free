# Hesora — هسورا

برای تست، build و اجرای سریع بدون نصب، از ریشهٔ پروژه `.\dev.ps1` را اجرا کنید. این فایل Qt در `G:\qt\6.12.0\mingw_64` و MinGW همراه آن را تنظیم می‌کند. برای اجرای سریع‌تر پس از تغییرات از `.\dev.ps1 -SkipChecks` و برای جزئیات از [راهنمای ساخت و اجرا](docs/BUILD_AND_RUN.md) استفاده کنید.

راهنمای اتصال به سرور PHP 8.4، فعال‌سازی Pro و بکاپ محلی/ابری در [اتصال وب و فضای ابری](docs/WEB_CLOUD_INTEGRATION.md) است.

در صفحهٔ «مشتریان»، «نمایش فاکتورها» سوابق همان مشتری را با تاریخ، نوع سند، وضعیت پرداخت، مبلغ و مانده نشان می‌دهد. «مشاهده فاکتور» کنار هر سند، پیش‌نمایش آن را باز می‌کند؛ مشتریان هم‌نام بر اساس شناسهٔ مستقل جدا می‌مانند.

نرم‌افزار دسکتاپ فارسی‌زبان برای مدیریت مشتریان، فاکتورها، پرداخت‌ها و خروجی‌های تجاری در Windows؛ با رویکرد آفلاین، حفظ مالکیت داده و محاسبات مالی دقیق. وب‌سایت: hesora.ir.

نسخهٔ رایگان شامل یک فروشگاه، حداکثر ۵۰ مشتری و ۲۰۰ فاکتور، قالب استاندارد Hesora و انتخاب محدود فونت رابط است.

> وضعیت فعلی: تست‌های هستهٔ Go و اتصال واقعی به سرویس PHP 8.4 اجرا شده‌اند. نصب نهایی و بازبینی کامل رابط گرافیکی باید جداگانه تأیید شوند.

## اهداف
- رابط کاربری فارسی و راست‌به‌چپ
- ذخیره‌سازی محلی با SQLite و مهاجرت نسخه‌بندی‌شده
- تفکیک منطق مالی از رابط کاربری و خروجی‌ها
- پشتیبانی از ریال، تومان و تاریخ شمسی
- خروجی قابل اتکا برای PDF و XLSX
- لایسنس مبتنی بر قابلیت‌ها بدون قفل‌کردن داده کاربر
- نصب و ارتقای امن در Windows بدون از دست رفتن داده‌ها

## ساخت نصب‌کننده Windows

پروژه WiX و اسکریپت بسته‌بندی در `installer/` و `scripts/build-installer.ps1` قرار دارند. ساخت MSI به Windows، Go 1.25.1، Qt 6.12.0/MinGW، WiX 6.0.2 و .NET SDK نیاز دارد. خروجی مورد انتظار `artifacts/installer/HesoraSetup-0.1.0-x64.msi` است. Build و نصب واقعی هنوز در محیط هدف تأیید نشده‌اند؛ مراحل و چک‌لیست در [راهنمای Installer](docs/WINDOWS_INSTALLER.md) ثبت شده‌اند.

## رابط پایه
ورودی برنامه در cmd/invoice-maker/ قرار دارد و تب‌های مشتریان، فروشگاه و تنظیمات را ارائه می‌کند. این UI اولیه است؛ Build و تست واقعی با Qt هدف هنوز تأیید نشده است.

## نمونه فنی
نمونه اولیه در cmd/qt-prototype/ قرار دارد و با MIQT و Qt 6 Widgets برای آزمایش نمایش فارسی، RTL و رویداد کلیک طراحی شده است. Build/Run واقعی آن با Qt 6.12 و MinGW هدف هنوز تأیید نشده است.

## چرخه توسعه
هر فاز در یک Branch مستقل که از آخرین main منشعب می‌شود توسعه خواهد یافت. پس از بازبینی، تست و مستندسازی، Pull Request به main ایجاد می‌شود. ادغام PR فقط با اجازه صریح مالک مخزن انجام خواهد شد.

داده‌های کاربر باید خارج از پوشه نصب برنامه نگهداری شوند و انقضای لایسنس نباید مانع دسترسی به داده‌های خود کاربر شود.

## محل داده در ویندوز
پایگاه داده در پوشه محلی داده کاربر نگهداری می‌شود، نه کنار برنامه. پوشه برای کاهش حذف تصادفی Hidden می‌شود؛ این کار جلوی حذف قطعی را نمی‌گیرد. بکاپ محلی و ارسال بکاپ ابری پیاده شده‌اند؛ بازیابی خودکار روی پایگاه دادهٔ باز هنوز ارائه نمی‌شود.
